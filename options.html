Translation, summaries, and key points can run privately on this device. Cloud providers remain optional.

Mozilla on-device translation

Uses the Bergamot engine and Mozilla language models. A language model is downloaded on first use, verified, and cached for offline translations. Article text never leaves this device.

Google Cloud Translation

Uses the official Basic v2 API with automatic source-language detection. Enable Cloud Translation and billing in your Google Cloud project first.

For safety, restrict this key to the Cloud Translation API and configure a usage quota in Google Cloud.
